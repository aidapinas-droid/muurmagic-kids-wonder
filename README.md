# MuurMagic Wall Wonders

Build me a children's wall sticker webshop called MuurMagic. Primary colors: purple #9B6BB5, mint #6DCBB8 and dusty rose #E8A0B0. Font style: playful and warm. The shop sells large wall stickers and party decoration for kids rooms, birthday parties and playrooms. Include: homepage with hero section, product grid, about section and contact. Tagline: Turn any wall into magic."
